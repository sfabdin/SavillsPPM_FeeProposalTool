The architecture is sound for a shared rollout: Box is the single source of truth with optimistic-concurrency sync, deletes are tombstoned, booked fees are frozen, access fails closed, and the rate grid never ships in code. The audit found two critical exposures (both fixed here) and several data-loss edge cases (hardened). The remaining actions are deployment-side — mostly a redeploy.

1Fixes applied in this pass

Critical

Confidential uploads were publicly deployable

uploads/ (client fee sheets, JPMC rate grids, revenue workbooks) was not excluded from Vercel deploys. Now blocked in .vercelignore, alongside _repo/ and staging copies. Redeploy to take effect, and delete prior Vercel deployments so old URLs stop serving.

Critical

Open API endpoints now require a Savills sign-in

/api/clockify (employee names, hours, project assignments) and /api/extract (spends Anthropic credit) were callable by anyone on the internet. Both now validate the caller's Box session against Box and require an @savills.us/.com login. All in-app callers send the token automatically.

High

Shrink guard on every Box push

If a browser's local copy has lost most of the projects Box knows about (corrupted cache, cleared browser, bad import), the push is now blocked with a visible error instead of overwriting the shared file. Deletes are unaffected (tombstones). Deliberate mass replacement: UFC_Box.forcePush() from the console.

High

Rolling weekly backups in Box

On top of Box's built-in version history, the app now keeps dated cold copies — projects-backup-YYYY-MM-DD.json in the same folder, refreshed weekly, last 8 kept (~2 months back). Created automatically by whoever signs in first; zero setup.

High

Import can no longer clobber the shared database

Merge is now newest-wins per project (an old backup can't overwrite newer work); "replace" requires typing REPLACE and refuses an empty file; the audit trail survives a replace.

Medium

Storage-full saves still reach Box

If the browser's local storage hits its quota, the save now still syncs to Box and raises a loud red pill, instead of throwing and losing the write.

Medium

Sync edge cases

Conflict-retry loop is capped (no runaway recursion under heavy simultaneous saving); signing out now flushes any unsynced changes before clearing the session.

2What the audit confirmed is already solid

  • Concurrency: every upload is etag-guarded; conflicts pull, merge newest-wins per project, and retry. Deletions propagate as tombstones (120-day retention, restorable).
  • Contract integrity: booked fees are frozen snapshots; later input drift flags stale instead of silently changing a signed number. Versions, change orders and rate-grid reconciliation all preserve history.
  • Access: fail-closed — an unknown login sees nothing; admin allowlist is explicit; impersonation is superuser-only; rate grid loads from Box post-login and is never cached or shipped in code.
  • Auth: OAuth 2.0 + PKCE, client secret server-side only; cross-tab refresh-token rotation is lock-coordinated with a recovery retry.
  • Visibility: the sync pill makes every failed/pending sync impossible to miss; unload warns if a save hasn't flushed.
  • Testing: tests.html asserts 24 engine + data-layer invariants against an in-memory shim — all passing after these changes.

5Known limits (accepted, documented)

  • Same-project simultaneous edits: merging is per whole project record — if two people edit the same proposal at the same moment, the newest save wins the record. Different projects never conflict. Fine at this team size; worth a record-level lock if editing becomes heavily parallel.
  • Local cache ceiling: browsers cap localStorage (~5 MB). Version snapshots grow records; if projects.json ever approaches ~4 MB, prune old versions. (Saves still reach Box even if the cache is full — fixed above.)
  • Close-tab flush is best-effort: a save made and the tab killed within ~1.5 s races the debounce; the app flushes on hide and warns on unload, but a hard kill can leave the save local-only until that browser next opens the app (it then merges up — not lost, just delayed).
  • API auth cost: each /api/clockify / /api/extract call now spends one Box identity check (~100 ms) — negligible at internal volume.
