Paste a fee matrix or proposal, or pull one in with Claude. The studio extracts the roster, normalises each staff title to a PPM rate-grid family, and validates every rate against the grid band [Col E cost floor ↔ Col B rack]. Where a rate sits below a title's cost floor it flags it and tells you which title the rate actually implies — then saves the lot as a project record you can open in the calculator.

Drop a revenue leader's "3. Detailed Revenues" workbook. This is a full book vs full book comparison: every sheet row is matched against the system — by Project ID first, then by name & client — and each row shows the name on both sides, total revenue, timeframe and staffing state, with the differences flagged; projects in the tool that the sheet never mentions are listed separately below. Staffing that WE seeded at a $0 placeholder rate doesn't block a revenue update (the dollars are override-driven either way), but a project someone has marked reconciled is never auto-changed. Nothing imports until you tick it — matched-and-unchanged and brand-new projects start unchecked on purpose, so a bulk import can never silently duplicate or create something you didn't mean to.
