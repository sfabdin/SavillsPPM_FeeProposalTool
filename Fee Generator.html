What this is.

The Fee Generator turns one-off proposal spreadsheets into a single, queryable system. Build a new pitch in the Universal Fee Calculator, or drop a past proposal into the Ingestion Studio and let it parse the roles, rates, phases and fees. Everything lands in the Projects Index — the institutional memory — which the Benchmarking Dashboard reads to answer "what did we charge for work like this before?" The same rate engine (the Macro 2024 grid, with its cost-rate floors) runs underneath all of it, so every number reconciles end to end.

Pillar 01

Author & benchmark

Every fee matrix is built in the calculator and saved to the database. Every historical proposal gets reconstructed and added, so comparables are one filter away.

Pillar 02

Plan vs. actual

When a project goes active, the "sold" hour plan becomes the baseline. Clockify actuals will reconcile against it by role and phase — coming in Phase 4.

Manual

How to use each tool.

Click a tool to expand

Step-by-step for the live modules. 


New here? The natural path is Ingestion Studio → review → Calculator → save for historicals, or straight into the Calculator for a fresh pitch — then watch it roll into Revenue Projections.

01Universal Fee Calculator
  1. Start a + New project from the Index, or open an existing one. The cover captures name, client, dates and status.
  2. In the catalog, tick the roles you need. Each carries a staff title, a tier (High / Mid / Low off the Macro 2024 rack rate), and a free-text project-role label.
  3. Per role, choose Grid (catalog rate minus the industry-standard adjustment, escalated) or Contracted (type a negotiated rate that bypasses the adjustment).
  4. Set FTE % per phase in the allocation matrix — this is where staffing is loaded, phase by phase.
  5. Tune global assumptions: hours/month, escalation, industry-standard adjustment (default 20%), client discount, and Rate Lock.
  6. Watch the cost-rate floor advisory — any role billed below its Col E/G cost rate is flagged (allowed, just surfaced).
  7. Use Reconcile to proposal → Fit to target to back-solve staffing per phase and a discount to a known total.
  8. Review the monthly schedule — toggle By phase vs Flatlined monthly, then export to Excel or PDF to incorporate into client facing proposal (Setup, Phase Matrix, Monthly Schedule).
Tip. Saving (or autosave on an existing project) writes the record straight to the Projects Index — no re-entry.
02Ingestion Studio
  1. Upload a proposal (PDF / XLSX / CSV) or paste a fee matrix or roster into the source box.
  2. Run the parse. It extracts project meta, phases (durations → months, per-phase fee), any one-time discount, and the roster — people, staff titles, project roles, teams, allocations and rates.
  3. Every rate is checked against the grid band [cost floor ↔ rack] and back-mapped to the closest title/tier. Below-floor and out-of-range rows are badged.
  4. Review and edit the roster and the extracted phase schedule. Fix any mismatched titles or allocations inline.
  5. Click Create project — it saves a record and opens it in the Calculator, where you fine-tune FTE by phase and reconcile to the fee.
No roster? Proposals that state a fee but only name contacts seed a starter team at grid rates — then use Fit to target in the calculator to solve their staffing.
03Projects Index
  1. Scan the portfolio KPIs at the top — pipeline, won, active, win rate and all-time fee.
  2. Search and filter by status, client, industry or lead; sort by fee or last updated.
  3. Each row shows the net fee computed by the same engine as the calculator (industry adjustment, contracted rates and escalation all honoured).
  4. Click a row to open and/or edit that project in the Calculator. Use Ingest proposal or + New project to create a new record.
  5. Export DB backs up every project to a JSON file; Import JSON restores or merges one — the sharing mechanism until cloud storage lands.
Backup habit. Records live in your browser for now — export the DB regularly until the Phase-5 cloud migration.
04Benchmarking Dashboard
  1. Open the Comparables finder and filter by client, industry, staff title, project size or project role to see matching historical rates.
  2. Switch to the Rates explorer for the min / median / max quoted and effective rate by staff title, plus how often we've priced below the cost floor.
  3. Use Project comparison to line up two or three past projects side by side — roles, rates, fees and structure.
  4. Carry the read-out back into the Calculator to price a new pitch with evidence, not guesswork.
Gets better with data. The more historicals you ingest, the sharper the benchmarks — this is the payoff for backtracking past proposals.
05Revenue Projections
  1. Set each project's projection rating (1–7) on the calculator cover — 1 Booked through 7 Dead Pursuit. It defaults from the lifecycle status; override it as confidence changes.
  2. Tag each group's service line ("Revenue attributed to") in the calculator so fees roll up to the right area.
  3. Open Revenue Projections to see every project's billings month-by-month across years, sorted by rating. Ratings 1–4 roll into the totals; 5–7 are greyed and excluded.
  4. Use the filters — client, revenue leader, service line, industry, year / quarter / month — to slice the forecast; pick a service line (e.g. Change Management) to pull out just that portion.
  5. Read the Projected (rated 1–4) and probability-weighted totals; click any project name to jump back into its calculator.
First cut of the reporting engine. This is the foundation for accruals, the monthly flash report and P&L — all driven off the same fee records, entered once.
